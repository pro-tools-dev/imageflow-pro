## 📥 安裝使用

### 方法1：便攜版本（推薦）
```bash
# 下載並解壓
tar -xzf ImageFlow-Pro-Portable.tar.gz
cd ImageFlow-Pro-Portable

# 安裝依賴
npm install

# 啟動應用
npm start
```

### 方法2：從源代碼運行
```bash
# 克隆倉庫
git clone https://github.com/pro-tools-dev/imageflow-pro.git
cd imageflow-pro

# 安裝依賴
npm install

# 啟動應用
npm start
```
