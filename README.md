## 📥 下載安裝

### Windows
1. 下載 `ImageFlow-Pro-Setup-1.0.0.exe`
2. 雙擊運行安裝程序
3. 按照提示完成安裝

### macOS
1. 下載 `ImageFlow-Pro-1.0.0.dmg`
2. 打開dmg文件
3. 將應用拖到Applications文件夾

### Linux
1. 下載 `ImageFlow-Pro-1.0.0.AppImage`
2. 添加執行權限：`chmod +x ImageFlow-Pro-1.0.0.AppImage`
3. 雙擊運行
